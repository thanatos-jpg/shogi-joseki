# 将棋定跡トレーナー

盤を自分で動かして、振り飛車を中心とした定跡を学ぶスマホ向けWebアプリです（ビルド不要の静的サイト）。

## 2つのモード
- **練習**: 自分で駒を動かす。一手ごとに〇／×と、×のときは正しい手順を表示。ヒント・答え表示つき。相手の応手は分岐からランダムに選ばれる。
- **通し**: 定跡の手順を一手ずつ進める／戻す。分岐では変化を選べる。自動再生も可。

## 使い方
`index.html` をブラウザで開く（またはリポジトリを GitHub Pages などで公開する）だけです。

## 定跡データの追加
`data/` に `.js` を作り、`index.html` の `<script>` に追加します。書式は `data/shikenbisha-vs-bogin.js` と `js/joseki.js` 冒頭を参照してください。

```js
JOSEKI_DATA.push({
  id: 'unique-id', group: '四間飛車', title: '対〇〇',
  user: 'w',            // 学習者が持つ側（b=先手 / w=後手）
  verified: false,      // 棋書等で確認できたら true
  summary: '一行の説明',
  moves: `
    ▲７六歩 △３四歩 {コメント}
    (▲２六歩 △８四歩)   ← 直前の手の別の候補（変化）
    ▲６六歩?  {よくある悪手の解説。「?」付きは練習で×時にこの解説を出す}
  `,                    // 文字列、または初手からの手順の配列（共通部分は自動で統合）
});
```

- 手は `▲７六歩` `△同歩` `▲５八金右` `△２二角成` `▲５五歩打` のように、手番記号つきで書きます。
- 最初に書いた手が主手順になります。
- 手順は読み込み時に将棋エンジンで検証され、反則手・手番違い・曖昧な表記はエラーになります。

## テスト
```
npm test
```
- 盤面エンジン（初期局面からの perft で既知の手数と一致するか、二歩・打ち歩詰めなど）
- `data/` 内の全定跡の合法性

> 検証できるのは「反則や表記の誤りがないこと」までです。定跡として正しいかは、棋書・棋譜で確認してください。
